# GSM-полив (ATmega328P + M590E)

Автономная система полива с управлением по SMS. Питание от АКБ 12 В и солнечной панели.

| Файл | Что это |
|---|---|
| `poliv_gsm.c` | Исходник прошивки (UTF-8) |
| `poliv_gsm.hex` | Готовая прошивка |
| `schematic.pdf` | Схема (промежуточная, пины в коде актуальнее) |
| `greenhouse.lay6` | Печатная плата (Sprint Layout 6) |
| `pump.txt` | Подключение насоса через реле с защитным диодом |

## Сборка и прошивка

```
avr-gcc -mmcu=atmega328p -Os -o poliv_gsm.elf poliv_gsm.c
avr-objcopy -O ihex -R .eeprom poliv_gsm.elf poliv_gsm.hex
avrdude -c usbasp -p m328p -U flash:w:poliv_gsm.hex
```

## Фьюзы (один раз, до первой прошивки)

| Фьюз | Значение | Зачем |
|---|---|---|
| lfuse | `0xE2` | Внутренний RC 8 МГц без деления на 8. С заводским `0x62` не работает UART |
| hfuse | `0xD1` | EESAVE: перепрошивка не стирает админа, расписания, калибровку |
| efuse | `0xFD` | BOD 2.7 В: при просадке питания сброс, а не порча EEPROM |

```
avrdude -c usbasp -p m328p -U lfuse:w:0xE2:m -U hfuse:w:0xD1:m -U efuse:w:0xFD:m
```

## Пины

| Назначение | Пин | Ножка DIP-28 |
|---|---|---|
| Реле 1–4 (включаются LOW) | PD4, PB1, PB2, PB3 | 6, 15, 16, 17 |
| Реле 5 (включается HIGH) | PC4 | 27 |
| Серво | PD5 | 11 |
| Поплавки 1–4 (замыкают на GND) | PD7, PB0, PC2, PC3 | 13, 14, 25, 26 |
| DHT11 | PD6 | 12 |
| Датчики почвы | ADC0, ADC1 | 23, 24 |
| АКБ (делитель 47k к +12 В / 20k к GND) | ADC5 | 28 |
| GSM RX / TX | PD0 / PD1 | 2 / 3 |
| GSM RI (пин I) | PD2 | 4 |
| GSM PWRKEY (пин K) | PD3 | 5 |

## SMS-команды

Регистр не важен, набирать в английской раскладке. N — номер реле 1–5.
В одной SMS можно несколько команд через `;` или с новой строки.

**С любого номера**

| Команда | Действие |
|---|---|
| `status` | Статус одной SMS |
| `N-on-M` | Включить реле N на M минут (`1-on-20.5`) |
| `N-off` | Выключить реле N |
| `6-angle-A` | Повернуть серво 0–180 |

**Только админ**

| Команда | Действие |
|---|---|
| `admin` | Стать админом (пока админ не задан) |
| `admin +79991234567` | Передать права |
| `N-auto-H-M` / `N-auto-H:MM-M` | Полив каждый день в H:MM на M минут |
| `N-auto` / `N-auto-off` | Включить / выключить сохранённое расписание |
| `balance *100#` / `balance` | Баланс (код запоминается) |
| `adc` | Сырые АЦП, RI, поплавки, время и его источник |
| `s1-dry` `s1-wet` `s2-dry` `s2-wet` | Калибровка датчиков почвы (`s1-dry-600` — числом) |
| `batt-12.76` | Калибровка напряжения АКБ по мультиметру |

Отвечает только на `status`, `balance`, `adc`. Неправильные SMS пересылаются админу
как `From <номер>: <текст>`. После включения админу приходит `Restart (причина)`.

## Формат status

```
R1:0 A:13 L13:00 D9.00     реле: вкл, час автополива, последний запуск, длительность
...
Sv:90d                     угол серво
F:1010                     поплавки
S:45 60                    влажность почвы, %
T:24 H:58                  DHT11
B:12.8V(100)               АКБ, % или crg (заряд)
```

## Особенности

- Модуль всегда в сети, контроллер спит. SMS будит его по линии RX (`+CMTI`), звонок — по RI.
  Сон модуля без провода DTR не работает (модуль уходит из сети).
- Время берётся из меток входящих SMS (M590 не поддерживает `AT+CLTS`).
  После рестарта автополив ждёт первую SMS — ответьте на `Restart` любым сообщением.
- Реле 1 и 3 работают только при замкнутом поплавке, реле 2 и 4 блокируются при замкнутом.
  Ниже 11.5 В реле не включаются.
